🐎 BRISNET Horse Race Handicapper

This version runs entirely on GitHub. There is no server to start or maintain.

Upload a BRISNET PDF

Because this app uses GitHub Actions for PDF processing, the PDF is uploaded to the repository rather than through this webpage.

1. Open the repository's input folder.
2. Click Add file → Upload files.
3. Upload your BRISNET Ultimate PP PDF and commit the change to main.
4. GitHub automatically runs the handicapper.
5. Return to this page and open the generated results.

What it extracts

Race summaries, post position, horse, morning line, running style, Prime Power, pace, E1/E2, late speed, speed, race rating, and average class where those fields are present.

Model % is a normalized handicapping score within each race, not a calibrated probability or guarantee of the outcome.
